Universal Variability Language

One common language for variability models.

UVL is a community-driven, textual language for feature models. It grew out of the MODEVAR initiative to let researchers and tools exchange variability models without translation headaches.

Try it in the browser Explore the ecosystem View on GitHub
  • Readable & versionable. Plain text with indentation, made for diffs and code review.
  • Built for exchange. One format understood by Flamapy, FeatureIDE, TraVarT, UVLHub and dozens more.
  • Extensible by levels. Start Boolean, opt into arithmetic and typed features only when needed.
  • Thriving ecosystem. Editors, solvers, configurators, datasets and AI assistants, all speaking UVL.
